# 3.2 Tài liệu Yêu cầu Sản phẩm (PRD)

## 1. Tổng quan
**Tên sản phẩm:** SmartTask AI Hub
**Mục tiêu:** Cung cấp hệ thống quản lý công việc thông minh có khả năng tự động hóa việc lên kế hoạch thông qua AI.

## 2. Tính năng Cốt lõi
- **Bảng Kanban (Kanban Board):** Hiển thị công việc theo các cột To Do, In Progress, Review, Done. Hỗ trợ kéo thả (Drag and Drop).
- **AI Task Breakdown:** Sinh tự động các sub-tasks dựa trên mô tả tổng quan.
- **AI PRD Generator:** Tạo tài liệu yêu cầu sản phẩm chuẩn form từ ý tưởng thô.

## 3. Phạm vi Dự án (Scope)
- **Giai đoạn 1 (Tuần 1-3):** Hoàn thiện Giao diện Frontend, Tích hợp AI Breakdown cơ bản.
- **Giai đoạn 2 (Tuần 4-6):** Xây dựng Backend, Database, Code Gen, Test tự động.

## 4. Rủi ro & Giảm thiểu
- **Rủi ro API AI chậm:** Cần tích hợp cơ chế Loading/Streaming trên UI.
- **Sai sót dữ liệu AI:** Cần cho phép người dùng chỉnh sửa (edit) lại kết quả mà AI tạo ra.
