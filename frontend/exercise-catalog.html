01. Architecture Design
Clean Architecture 4 Tầng
Entity Exercise nằm tại Domain Core, giao tiếp qua IExerciseRepository mà không phụ thuộc vào file JSON hay hệ quản trị PostgreSQL.
02. Architecture Patterns
Cache-Aside & Server-Driven UI
Tích hợp bộ nhớ đệm In-Memory/Redis lưu trữ chỉ mục nhóm cơ giúp tìm kiếm bài tập dưới 5ms (thỏa mãn NFR-P02 sub-2s).
03. UML & System Modeling
Sequence & Class Diagrams
Sơ đồ tuần tự thể hiện tương tác khi AI phát hiện mỏi cơ DOMS ≥ 7: tự động loại bỏ bài tập squat/deadlift và thay bằng mobility/stretching.
04. Database Design
CSDL Quan Hệ Chuẩn 3NF
Bộ dữ liệu được chuẩn hóa thành 2 bảng exercises và exercise_secondary_muscles, loại bỏ hoàn toàn dư thừa dữ liệu (Transitive Dependency).
05. API Design
RESTful OpenAPI 3.0
Cung cấp các endpoint GET /api/v1/exercises hỗ trợ phân trang, lọc theo body_part, target và tìm kiếm toàn văn.
06. Design Patterns
Strategy & Specification Pattern
Áp dụng SafeExerciseSpecification để lọc bài tập an toàn và WorkoutStrategyFactory để sinh buổi tập theo hình thức Strength / HIIT / Mobility.
